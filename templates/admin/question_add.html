Required format

The PDF must contain selectable text (not a scanned image) laid out like this — each question separated by a blank line:

  • Start each question with a number, e.g. Q1. or 1)
  • Optionally add marks in square brackets at the end of the question line, e.g. [2] (defaults to 1)
  • List options as A), B), C), D) ...
  • Mark the correct option with a trailing asterisk *

Example

Q1. What is the capital of France? [2]
A) London
B) Paris *
C) Berlin
D) Madrid

Q2. Which planet is known as the Red Planet?
A) Venus
B) Mars *
C) Jupiter
D) Saturn

Tip: type this into any Word/Docs file using the exact layout above, then "Print → Save as PDF" to produce an importable file. You can download the sample text above as a starting point.
